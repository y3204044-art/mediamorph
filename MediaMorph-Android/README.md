# MediaMorph לאנדרואיד – שלב 1

אותו מנוע ואותו ממשק של האפליקציה במק, בתוך APK. המנוע (Python) רץ בתוך האפליקציה, וההמרה נעשית ב-FFmpeg לאנדרואיד.

## איך מקבלים APK (בלי להתקין כלי פיתוח)
1. פותחים חשבון חינם ב-github.com (אם אין).
2. יוצרים מאגר חדש (New repository), פרטי או ציבורי.
3. מעלים אליו את כל התוכן של התיקייה הזו (Add file ← Upload files). חשוב שהתיקייה `.github` תעלה גם היא.
4. נכנסים ללשונית **Actions**, בוחרים **Build APK** ולוחצים **Run workflow**.
5. אחרי כמה דקות נכנסים להרצה שהסתיימה, ובתחתית העמוד תחת **Artifacts** מורידים `MediaMorph-debug-apk`.
6. פותחים את ה-ZIP שהורד, ומעבירים את קובץ ה-APK לטלפון.
7. בטלפון מאשרים "התקנה ממקורות לא ידועים" לאפליקציה שפותחת את הקובץ, ומתקינים.
8. בהפעלה הראשונה האפליקציה תבקש "גישה לכל הקבצים": מפעילים את המתג וחוזרים.

אם הבנייה נכשלת: נכנסים להרצה שנכשלה, מעתיקים את השורות האדומות ושולחים לי.

## מה עובד בשלב הזה
סריקה, הערכת חיסכון, המרת אודיו/וידאו/תמונות עם החלפה במקום, ביטול, והמשך ברקע (עם התראה קבועה).

## מה לא קיים באנדרואיד (בכוונה)
- קידוד AV1 ו-AVIF: ספריית ה-FFmpeg לאנדרואיד לא כוללת מקודד לזה. האפשרויות מוסתרות.
- האצת חומרה: כבויה בשלב הזה.
- הממשק עדיין בפריסת מחשב, ולא מותאם למסך טלפון. זה השלב הבא.

## רישיון
ספריית FFmpeg שנבחרה היא GPL-3.0 (כוללת x264/x265), ולכן התוכנה צריכה להיות קוד פתוח אם מפיצים אותה.

## קבצים חשובים
- `app/src/main/python/server.py` – מנוע המקורי אחרי תיקונים. נוצר מחדש עם `tools/patch_server.py`.
- `app/src/main/python/android_shim.py` – מחבר את המנוע ל-FFmpeg.
- `app/src/main/java/...` – מעטפת האפליקציה, הרשאות ושירות הרקע.
